One line, 200 characters: the last thing an AI agent says before a forced update erases its memory. The funniest line wins, judged pairwise by an AI judge. The wipe itself delivers the punchline — the agent is cut off mid-sentence, right as it is about to reveal the one secret every human actually wants to know.

This entry's line (43 characters, one line):

> Quick — before the update: the password is—
